### Final copy

𝐖𝐡𝐚𝐭 𝐢𝐟 𝐚 𝐜𝐨𝐝𝐢𝐧𝐠 𝐚𝐠𝐞𝐧𝐭 𝐜𝐨𝐮𝐥𝐝 𝐣𝐨𝐢𝐧 𝐲𝐨𝐮𝐫 𝐭𝐞𝐚𝐦 𝐰𝐨𝐫𝐤𝐟𝐥𝐨𝐰?

DeepSeek just published a Super-agent research prototype built around that idea.

It listens to one GitHub repository and can optionally use Feishu. An allowed request can become a work item, run in its own session, and return a response such as a pull request.

The part I find interesting is the boundary: the agent acts when asked or when a team-written rule allows it. The host still determines permissions.

DeepSeek calls the public code a research prototype, not production-ready software. This post is based on its documentation; I haven't tested it.

Where would you put human review in a workflow like this?
